# 0043 - Domain Vocabulary And UI Language

## Status

Accepted

## Context

V1 leaks technical parser terms and does not speak in BI/data language.

## Decision

Use words such as dataset, rows, columns, delimiter, header row, measure, dimension, time field, missing values, malformed row, and compressed CSV.

## Consequences

Errors and inference explanations become understandable without developer knowledge.

## Alternatives Considered

Raw exception strings were rejected.
