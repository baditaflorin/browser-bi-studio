# 0010 - GitHub Pages Publishing

## Status

Accepted

## Context

The live GitHub Pages URL is a first-class deliverable from the first scaffold.

## Decision

Serve GitHub Pages from `main` branch `/docs`.

Build output is generated by Vite into `docs/`. `docs/` is intentionally not gitignored. The base path is `/browser-bi-studio/`. `docs/404.html` is copied from `docs/index.html` for SPA fallback.

## Consequences

- Publishing is a normal commit and push.
- Rollback is a normal git revert.
- Build artifacts live in the repo by design.

## Alternatives Considered

- `gh-pages` branch was rejected to keep source and published artifacts reviewable together.
- GitHub Actions Pages deploy was rejected because this project intentionally uses local hooks instead of Actions.
