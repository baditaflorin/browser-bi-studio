# 0070 Documentation Reality Alignment Process

- Status: accepted
- Date: 2026-05-09

## Context

The README is the first contract a stranger sees.

## Decision

Every README feature claim must correspond to a working control or test. Partial support moves to limitations. The live URL, repository URL, PayPal link, version, and commit remain prominent.

## Consequences

Docs may be less flashy, but they will be more trustworthy.

## Alternatives Considered

Keeping aspirational claims was rejected because Phase 3 is about usability rather than marketing.
