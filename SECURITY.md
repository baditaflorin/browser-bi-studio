# Security Policy

## Supported Versions

The `main` branch and latest semver tag are supported.

## Reporting

Please report vulnerabilities privately to:

security@badita.dev

If that address is unavailable, open a GitHub security advisory at:

https://github.com/baditaflorin/browser-bi-studio/security/advisories

## Scope

Browser BI Studio is a static GitHub Pages app. It must not contain committed secrets and must not require frontend-held secrets.
